# CIS 285 Lab 7 – Student Task Tracker: Architecture and Design

A web app for students to track courses, assignments, due dates and grades, with email reminders
before deadlines. This repository holds the AI-assisted architecture and design work for Lab 7.

## Lab steps and where to find each

| Step | What | Where |
|------|------|-------|
| 1 | Claude Code / Codex installed in VS Code | Done locally (no repo file) |
| 2 | ChatGPT connected to this GitHub repo | Done in ChatGPT (no repo file) |
| 3 | Base architecture generated with **Spec Kit** | [`.specify/memory/constitution.md`](.specify/memory/constitution.md), [`specs/001-student-task-tracker/`](specs/001-student-task-tracker/) |
| 4 | Alternative architecture generated with **Claude Code** | [`docs/architecture-alternative.md`](docs/architecture-alternative.md) |
| 5 | ChatGPT review of both architectures | `docs/reviews/` |
| 6 | Decision and ChatGPT consolidation instructions | `docs/decision.md`, `docs/consolidation-instructions.md` |
| 7 | Consolidated requirements, architecture and design | `docs/consolidated/` |
